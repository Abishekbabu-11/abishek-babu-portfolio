# Abishek Babu — Software Tester Portfolio

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling and animations
- `script.js` — scroll progress and reveal animations

## How to use
1. Keep all three files in the same folder.
2. Double-click `index.html` to preview it in a browser.
3. Social links have already been added: LinkedIn, GitHub and Instagram.

## LinkedIn
LinkedIn does not normally host a custom HTML/CSS website directly as a portfolio page. Publish this site using a web host (for example GitHub Pages, Netlify or Vercel), then add the live portfolio URL to your LinkedIn **Featured** section and/or website/contact information.
